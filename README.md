# 업다운 숫자 게임

쉬는 시간에 혼자 가볍게 즐기는 숫자 맞히기 게임입니다.
컴퓨터가 정한 1~100 사이의 숫자를 업/다운 힌트를 보며 **7번 안에** 맞혀 보세요.

## 실행 방법
`index.html`을 더블클릭하면 브라우저에서 바로 열립니다.
설치할 것이 없고, 인터넷 연결 없이도 동작합니다.

## 게임 규칙
- 숫자를 입력하고 [확인]을 누르거나 Enter를 칩니다.
  - 정답보다 크면 **▼ 더 작은 수를 입력하세요**
  - 정답보다 작으면 **▲ 더 큰 수를 입력하세요**
  - 맞히면 **정답입니다!** 와 함께 꽃가루가 떨어집니다.
- 기회는 7번입니다. 시도 횟수와 남은 기회가 항상 보입니다.
- 4번 틀린 뒤부터 **짝수예요 / 홀수예요** 힌트가 나옵니다.
- 7번 모두 틀리면 **실패! 정답은 OO** 로 정답을 알려 줍니다.
- 맞히거나 실패하면 입력이 잠깁니다. [다시 시작]을 누르면 새 숫자로 처음부터 합니다.
- 빈 칸, 1~100 밖의 수, 소수, 이미 입력한 숫자는 시도 횟수로 세지 않습니다.

## 파일 구성
| 파일 | 내용 |
|---|---|
| `index.html` | 게임 전체 (HTML·CSS·JavaScript 한 파일) |
| `PRD.md` | 요구사항 문서: 규칙, 직접 정한 사항, 디자인, 완료 기준 |
| `STEPS.md` | 만드는 순서: 뼈대 → 기능 → 디자인 → 점검 |

## 만든 과정
| 커밋 | 단계 |
|---|---|
| 뼈대생성 | 화면 요소 배치 |
| 기능생성 | 게임 규칙, 입력 검사, 짝홀 힌트, 다시 시작 |
| 디자인 | 어두운 테마, 노란 강조색, 업/다운 초록·빨강, 축하 효과 |
| 점검 | 전체 시나리오 테스트, PRD를 실제 화면에 맞게 수정 |
